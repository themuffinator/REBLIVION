Oblivion Rerelease

Windows x64 Nightly Build

This archive contains a packaged oblivion/ directory for the Quake II rerelease port of Oblivion.

The exact build identity for this package is recorded in VERSION.txt inside the bundled oblivion/ directory.

This release archive contains an oblivion/ directory with:

  • game_x64.dll
  • pak0.pak
  • README.html
  • VERSION.txt

Installation

  1. Locate your Quake II rerelease installation directory.
  2. Extract this archive into the rerelease root so the bundled oblivion/ directory lands beside baseq2/.
  3. Allow existing files inside oblivion/ to be replaced if you are upgrading an earlier nightly build.
  4. Launch the rerelease with +set game oblivion.

This package is intended for the rerelease runtime and already includes the packaged Oblivion assets in pak0.pak.

Expected Layout

oblivion/
  game_x64.dll
  pak0.pak
  README.html
  VERSION.txt

Versioning

Nightly builds use a semantic base version from the repository VERSION file and append nightly identifiers in the release tag and archive name.

The format is:

v<base-version>-nightly.YYYYMMDD.HHMMSS.g<commit>

Example:

v0.1.0-nightly.20260317.231500.g1a2b3c4

Notes

Item Purpose
game_x64.dll Windows x64 game module for the Quake II rerelease.
pak0.pak Packaged Oblivion assets and data from this repository's pack/ tree.
VERSION.txt Human-readable build metadata including the exact nightly tag, UTC build time, and source commit.
