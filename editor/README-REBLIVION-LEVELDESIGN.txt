REBLIVION level-design support
==============================

This archive contains separate editor payloads for level designers:
- `reblivion-netradiant-custom-...zip` extracts into the NetRadiant-Custom root.
- `reblivion-trenchbroom-...zip` extracts into the TrenchBroom root.

Both packs start from the stock Quake II rerelease editor definitions, then
append a generated runtime delta from the live REBLIVION source tree. That
preserves the full retail q2re surface while also exposing the extra rerelease
and REBLIVION-specific entities level designers can actually use in REBLIVION.
